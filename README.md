# 🌶️ Hot & Spicy — Restaurant Website

**Hot & Spicy** is a static restaurant website designed to showcase a modern and attractive restaurant interface using **HTML, CSS, and JavaScript**.

The website includes multiple pages and interactive sections such as a homepage, menu, about/learn more page, testimonials, and a gallery slider.

## ✨ Features

* 🏠 **Home Page** – Hero section, featured menu items, testimonials, about section, and gallery.
* 🍕 **Menu Page** – Displays the restaurant's food and drink offerings.
* 📖 **About / Learn More Page** – Provides detailed information about the restaurant.
* 💬 **Testimonials Section** – Displays customer reviews and feedback.
* 🖼️ **Gallery Slider** – Showcases restaurant and food images through a slider.
* ⚡ **Interactive Elements** – JavaScript is used for navigation and interactive UI components.

## 🛠️ Technologies Used

* **HTML5** – Website structure and content
* **CSS3** – Styling and layout
* **JavaScript** – Interactivity and dynamic UI behavior

## 🚀 Getting Started

Since this is a static website, no backend or database setup is required.

### 1. Clone the repository

```bash
git clone https://github.com/Chah2004/hot-and-spicy.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd hot-and-spicy
```

### 3. Run the website

Simply open `index.html` in your browser.

You can also use **VS Code Live Server** for a better development experience.
